# 书链搜 · 小说链接聚合搜索（纯前端）

仅整理**公开链接元数据**（书名、封面、简介、原站 URL），搜索后一键跳转至原网站阅读。不存储、不解析、不转载任何小说正文。

## 功能

- 搜索框：按书名、作者、标签、简介关键词检索
- 结果卡片：标题 + 封面 + 简介 + 来源站点
- 点击卡片：新标签页打开原站链接（`rel="noopener noreferrer"`）
- 来源筛选：按平台 Chip 过滤
- 深色/浅色主题，移动端适配
- 零后端：静态文件即可部署

## 目录结构

```
├── index.html          # 主页面
├── styles.css          # 样式
├── app.js              # 搜索逻辑
├── data/novels.json    # 书库索引（自行维护）
├── assets/             # 静态资源
└── README.md
```

## 本地预览

纯静态站点需通过 HTTP 访问（`fetch` 无法直接读本地 `file://`）：

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：Node
npx serve . -p 8080
```

浏览器打开 `http://localhost:8080`。

## 部署

可上传至任意静态托管：

| 平台 | 说明 |
|------|------|
| GitHub Pages | 推送到 `gh-pages` 分支或 Actions |
| Cloudflare Pages | 构建命令留空，输出目录为根目录 |
| Vercel / Netlify | 拖拽文件夹或连接仓库 |
| 对象存储 | 阿里云 OSS、腾讯云 COS 开启静态网站 |

## 维护书库 `data/novels.json`

每条记录字段说明：

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | 是 | 唯一标识 |
| `title` | 是 | 小说名称 |
| `url` | 是 | 原站阅读页完整 URL（须以 `http` 开头） |
| `bookId` | 否 | 原站书籍 ID，用于自动生成封面 |
| `author` | 否 | 作者 |
| `source` | 否 | 来源平台名称（用于筛选与封面解析） |
| `cover` | 建议填写 | **原站封面图直链**。起点系推荐 `https://bookcover.yuewen.com/qdbimg/349573/{bookId}/180`；纵横/晋江/QQ 可用 `https://bookcover.yuewen.com/{bookId}/180` |
| `description` | 否 | 简短简介（建议自行撰写或引用原站公开简介） |
| `tags` | 否 | 标签数组，参与搜索 |

**合规建议：**

1. 只收录指向**正版或原发布平台**的公开链接
2. 不收录盗版、全文镜像、未授权转载站
3. 封面建议使用原站 CDN 或自有图床，注意跨域与防盗链
4. 定期抽查链接是否失效

## 合规声明

本站仅做公开链接整理与搜索跳转，所有阅读行为在第三方原站完成。若发现侵权或错误链接，请从 `novels.json` 中移除并重新部署。

## 许可

示例数据中的书名与元数据仅供演示搜索功能，链接指向各平台公开页面。实际运营时请自行核实版权与链接有效性。
